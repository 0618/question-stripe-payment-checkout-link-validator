# Mock Interview: Stripe Payment Checkout Link Validator

**Domain**: Frontend (React)
**Style**: HackerRank
**Company**: Stripe
**Difficulty**: Senior

## Description
Implement a robust Checkout Link Management component. 

Users need to be able to type a "slug" for their checkout link (e.g., `stripe.com/pay/my-slug`). As they type, you must validate the slug against a simulated backend API. 
The component must remain responsive and robust against rapid user input and unpredictable network latency.
Show real-time availability status (Checking..., Available, Taken, Invalid).

## Instructions for Candidate
- Your task is to implement/fix the functionality described above.
- Focus on performance, clean code, and accessibility.
